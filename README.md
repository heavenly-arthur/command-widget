# Command Widget

Персональное офлайн-приложение для macOS с командами и шпаргалками по Kubernetes, Helm, Flux, Linux, Ansible и Terraform.

Command Widget живёт в строке меню и открывает плавающую панель, которую можно держать поверх остальных окон. Приложение предназначено для одного Mac и не требует аккаунта, интернета или API-ключей.

## Возможности

- 48 стартовых команд: по 8 в каждой из шести категорий;
- подробные локальные объяснения, теги и примеры запуска;
- поиск по названию, команде, категории, тегам и тексту справки;
- копирование команды в системный буфер обмена;
- сворачиваемые категории: при запуске все они закрыты;
- порядковые номера внутри категории;
- ручная сортировка команд перетаскиванием внутри категории с сохранением порядка;
- плавающая панель, доступная во всех Spaces и рядом с полноэкранными приложениями.

## Требования

- macOS 14 или новее;
- Xcode 26 или совместимый Swift 6.1 toolchain.

## Сборка и запуск

В корне проекта:

```zsh
./scripts/build_app.sh release
open "build/Command Widget.app"
```

Скрипт собирает и локально подписывает приложение. Готовый bundle находится в `build/Command Widget.app` и намеренно не попадает в Git.

Для разработки и запуска тестов:

```zsh
swift test --disable-sandbox
```

## Данные

Каталог сохраняется в:

```text
~/Library/Application Support/CommandWidget/commands.json
```

Файл содержит версию схемы, встроенного каталога и пользовательский порядок. При обновлении приложения добавляются только новые встроенные записи; существующие изменения и порядок не перезаписываются. Повреждённый JSON не заменяется автоматически.

## Приватность

Приложение работает полностью локально:

- без сетевых запросов;
- без AI и внешних API;
- без телеметрии и аналитики;
- без аккаунтов и облачной синхронизации;
- без глобальных горячих клавиш.

## Структура

```text
Sources/CommandWidget/       интерфейс SwiftUI и AppKit-панель
Sources/CommandWidgetCore/   модель, локальное хранилище, поиск и порядок

Tests/                       unit-тесты

docs/qa/                     отчёты проверок
scripts/build_app.sh         сборка персонального .app bundle
```
