# Command Widget v0.2.0

Расширенный каталог и собственные категории для персонального офлайн-приложения macOS.

## Новое после v0.1.0

- 230 встроенных команд в 22 категориях для DevOps, Frontend, Backend и QA.
- Первоначальный выбор ролей, категорий и 66 подкатегорий инструментов; выбор можно изменить в панели.
- Вложенный каталог «категория → инструмент → команда», поиск внутри выбранных инструментов и сохранение порядка команд внутри подкатегории.
- Собственные категории и подкатегории: создание, переименование, управление видимостью и удаление с подтверждением.
- Отдельное локальное хранение пользовательской структуры в `custom-taxonomy.json`.
- Настройка каталога и пользовательских категорий внутри изменяемой по размеру панели.

## Установка и обновление

Требования: macOS 14 или новее и Mac с Apple Silicon (arm64).

1. Завершите предыдущую версию через меню приложения, если она запущена.
2. Скачайте `Command-Widget-v0.2.0-macOS-arm64.zip` и распакуйте архив.
3. Перенесите `Command Widget.app` в `Applications` и откройте его.
4. Значок приложения появится в строке меню macOS.

Приложение подписано локальной ad-hoc подписью и не нотарифицировано Apple. При первом запуске может потребоваться подтверждение через «Системные настройки → Конфиденциальность и безопасность → Открыть всё равно».

Контрольная сумма архива находится в `SHA256SUMS.txt`. Для Intel Mac доступна сборка из исходников по README; готовый архив предназначен только для Apple Silicon.

Существующие команды и их порядок сохраняются при обновлении; старые настройки категорий мигрируют с включением соответствующих инструментов. Работа приложения полностью локальна, без аккаунтов и сетевых запросов.

## Проверки и ограничения

- 48 автоматических тестов прошли без ошибок, включая локальное хранение, миграции, поиск, порядок и пользовательскую таксономию.
- Release-сборка выполнена; подпись, версия, архитектура и целостность архива проверены.
- В собственных категориях пока можно организовывать только структуру: добавление пользовательских команд запланировано отдельно.
- Полный ручной регрессионный проход интерфейса, Spaces и полноэкранных приложений для этого релиза не выполнялся.
