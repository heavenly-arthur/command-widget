# Command Widget

## Назначение

Персональное нативное приложение для macOS, которое держит под рукой CLI-команды и шпаргалки для ролей DevOps, Frontend, Backend и QA.

## Владелец и среда

- Один пользователь и один личный Mac.
- Распространение другим пользователям и публикация в App Store не требуются.
- Приложение работает полностью офлайн.

## Продуктовые инварианты

- Нет AI, внешних API, телеметрии, аккаунтов и облачной синхронизации.
- Нет глобальной горячей клавиши.
- Пользовательские данные и подробные объяснения команд хранятся локально.
- Панель может оставаться поверх окон других приложений.
- Потеря пользовательских записей при обновлении приложения недопустима.

## Основные сценарии MVP

1. Открыть приложение из строки меню и показать или скрыть плавающую панель.
2. При первом запуске выбрать роли, CLI-категории и конкретные инструменты внутри них, а позже изменить выбор в панели.
3. Найти команду по тексту, названию, категории или тегам внутри выбранных категорий и инструментов.
4. Скопировать команду в буфер обмена.
5. Открыть локальное подробное объяснение команды.
6. Добавить, отредактировать или удалить собственную запись.
7. После перезапуска увидеть сохранённые изменения и настройки каталога.

## Модель записи

Каждая запись содержит стабильный идентификатор, название, команду, категорию, теги, краткое описание, подробное объяснение, примеры и дату изменения. Категория выбирается из базового списка, а инструментальная подкатегория определяется локальной таксономией по категории, CLI и тегам. Модель не должна мешать будущему добавлению пользовательских категорий.

## Цикл совершенствования

Итерация проходит через PM → Dev → QA. PM выбирает минимальный инкремент и задаёт acceptance criteria; Dev реализует и передаёт проверяемую сборку; QA выносит доказуемый вердикт. Дефекты возвращаются в текущую итерацию, а новые идеи попадают в backlog и не расширяют её молча.
